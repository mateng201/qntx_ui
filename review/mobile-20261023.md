# Mobile 与 Nx 迁移验收

日期：2026-10-23。分支：`mobile`，基于 `main` 的 `97e3dcb`。本次没有修改远端或线上部署。

## 交付内容

- 原 Web 移入 `apps/web`，保留三屏横向导航、原悬停反馈及独立 Logo 演示。
- `apps/mobile` 使用 Expo + 原生 React Native 组件实现 Overview / Protocols / About，底部标签、纵向阅读、安全区域、外链及 Android 返回首页处理。
- 两端共同消费 `packages/content` 与 `packages/design-tokens`。共享包没有 React、Astro、Expo 或 DOM 依赖。
- Nx 24.0.0 管理四个项目的任务、缓存、依赖图及 affected 范围；两端通过各自工具构建。
- qntx Oxlint / Oxfmt / strictest TypeScript 配置继续生效。独立 ESLint 任务只承担边界规则，并覆盖 `.astro` 的导入。
- React / React DOM 为同一份 19.3.0；Expo 58.0.17、React Native 0.88.0 与配套原生模块按 Expo 推荐组合安装，锁文件统一在仓库根目录。

## 验证范围

- 四个项目分别执行类型检查，qntx Oxlint、格式检查及四项目边界检查。
- 六个真实违规探针均被拒绝，一个合法共享导入通过；包含 Web → Mobile、Mobile → Web、共享包 → 原生依赖 / Web、浏览器全局访问，以及 `.astro` 前置脚本跨端导入。
- Nx affected 实测：`apps/mobile/src/App.tsx` 只影响 `mobile`；`packages/content/src/index.ts` 影响 `content`、`mobile`、`web`。
- Web 静态构建与原 36 项 Chrome 回归检查。
- Expo Doctor：20/20 检查通过，原生依赖与 React 没有重复版本。
- Mobile 的 Android / iOS Hermes 资源与浏览器资源导出。
- Mobile 浏览器预览的 5 项用例：三页切换与活动状态、外链在独立窗口打开、320×640 / 390×844 / 768×1024 下的布局、卡片阅读和固定标签栏。捕获页面及控制台错误，确认组件没有运行时错误。

手机端截图保存在本地 `artifacts/mobile-20261023/overview.png`、`protocols.png`、`about.png`，沿用 `.gitignore`，不提交截图或缓存。
